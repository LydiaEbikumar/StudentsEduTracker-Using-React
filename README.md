# StudentsEduTracker Using React

This project is a student education tracker application built with React. It allows users to manage academic records by adding, editing, and tracking student performance efficiently.



### Usage

First install the dependencies

```bash
npm install
```

Then run the application

```bash
npm start
```

Once it’s running, open your browser

```bash
http://localhost:3000
```

---

### Folder Structure

```bash
/src
  /components
    StudentForm.js
    StudentList.js
    StudentDetails.js
  App.js
  index.js
```

---

### Cleanup

To stop the server

```bash
Ctrl + C
```

To remove installed packages

```bash
rm -rf node_modules
```
